# Student Helpdesk Chatbot

## Overview
The Student Helpdesk Chatbot is an intent-based chatbot designed to assist students with queries related to admissions, courses, and exams. It leverages a CSV dataset for intent matching and responses, making it easy to extend with new intents and responses.

## Features
- **Intent Matching**: Understands and processes student queries based on defined intents.
- **Extensible**: Easily add new intents and responses to meet evolving student needs.
- **User-Friendly**: Provides a seamless interaction experience for students seeking information.

## Technologies Used
- Python
- CSV for data storage
- Natural Language Processing (NLP) techniques for intent recognition
